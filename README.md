# PDF 去水印工具

双击运行，自动去除扫描版PDF中的浅色水印并增强清晰度。

## 使用方法

### 方式一：直接运行（推荐）
下载 `dist/PDF去水印工具.exe`，双击运行，浏览器自动打开。

### 方式二：源码运行
```bash
pip install -r requirements.txt
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| 水印阈值 | 230 | 灰度高于此值的像素视为水印（180-250） |
| 输出DPI | 250 | 输出分辨率（150-400） |
| 增强系数 | 1.10 | 对比度增强（1.0-1.3） |

## 原理

1. 逐页渲染PDF为高清图片
2. 浅色像素（min(R,G,B) > 阈值）→ 纯白
3. 色阶拉伸增强文字对比度
